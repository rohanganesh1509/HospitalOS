Educational Memory Model:

Processes are assigned page requirements deterministically based on treatment duration. If physical memory is exhausted, allocation fails (MEMORY_ALLOCATION_FAILED) and the process enters WAITING state until frames are freed.

What this demonstrates

Paging Architecture

Processes address memory in virtual pages (4 KB), while physical RAM is divided into fixed frames. Non-contiguous frame allocation eliminates external fragmentation.

Deterministic Allocation & Cleanup

Each patient admission allocates frames predictably. When a patient's treatment completes (TERMINATED), all held frames are automatically freed back to the free list.

Memory Pressure & Blocking

When high memory pressure occurs and all 16 frames are occupied, new processes cannot execute until running processes terminate and yield their frames.
