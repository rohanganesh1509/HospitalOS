OS Resource Semantics:

When a process requests an unavailable resource, HospitalOS transitions its state from RUNNING → WAITING. When another process releases that resource, the highest-urgency waiter is unblocked to WAITING → READY.

What this demonstrates

  

    

      Safe state
      
There exists at least one order in which every process can finish using currently available resources plus resources released by completed processes.

    

    

      Unsafe state
      
The algorithm cannot find a complete safe sequence. This does not automatically mean a deadlock has already occurred, but entering an unsafe state risks deadlock if processes claim their maximum need.
