Educational Note on System Calls:

In a production operating system, user applications transition into kernel space via software interrupts or the syscall assembly instruction. In this educational web simulation, these calls model system service routines (e.g. resource_request(), memory_allocate(), lock_acquire(), process_exit()) with identical state-machine semantics.
